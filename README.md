# EcoControl

[English README](README.en.md)

Демонстрационный сервис экологического контроля. Оператор загружает видео, выбирает имитируемую камеру и микрофон и проверяет результаты YOLO, EasyOCR и YAMNet. Аудио берётся из дорожки видео. Выбор источника сохраняется в результатах анализа.

## Запуск на Windows

Из папки `eco-control` в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1
```

Откройте http://127.0.0.1:8000. Вход оператора для локальной демонстрации — `admin / admin`. При первом анализе модели могут скачивать веса. Для запуска с PostgreSQL задайте `ECO_DATABASE_URL` в формате `postgresql+psycopg://user:password@localhost/eco`. По умолчанию используется локальный SQLite.

### Ускорение на видеокарте NVIDIA

Для YOLO и EasyOCR установите сборку PyTorch с CUDA в окружение проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install "torch==2.8.0+cu128" "torchvision==0.23.0+cu128" --index-url https://download.pytorch.org/whl/cu128
```

Перезапустите сервер после установки. При доступной CUDA YOLO и EasyOCR используют видеокарту, иначе они работают на процессоре. YAMNet в текущем окружении Windows работает на процессоре.

## Демонстрация

1. Войдите как оператор и загрузите MP4, MOV, MKV, AVI или WebM до 100 МиБ. Для демонстрации аудиоанализа возьмите короткий ролик со слышимым двигателем в первые 10 секунд.
2. Просмотрите результат, откройте сохранённый кадр и подтвердите или отклоните наблюдение.
3. Скачайте ZIP. Сервис сверит SHA-256 видео перед выдачей архива. Внутри находятся исходник, результат ML в JSON, текстовый отчёт и кадр при наличии.
4. Выйдите из панели. Страницы материалов и операции оператора проверяют сессию.

Виртуальные источники обозначают происхождение тестового файла. Панель показывает длительность ролика и помечает неизвестный источник звука. Текущий анализ не измеряет длительность работы оборудования и не определяет марку автомобиля.

Для установки вне локальной демонстрации задайте `ECO_ADMIN_PASSWORD` и `ECO_SESSION_SECRET`. При использовании HTTPS включите `ECO_SECURE_COOKIE=1`.
