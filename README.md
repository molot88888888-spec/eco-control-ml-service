# EcoControl — Защищённый ML-сервис экологического контроля

Курсовой проект: разработка интеллектуальной системы для выявления продолжительной работы автомобильных двигателей на дворовых территориях по видео- и аудиоданным.

## Основные возможности
- **Видеоанализ**: Поиск автомобилей (YOLOv8) и распознавание номеров (EasyOCR с поддержкой кириллицы).
- **Аудиоанализ**: Детекция работающего двигателя с помощью нейросети YAMNet.
- **Интерфейс оператора**: Подтверждение/отклонение событий.
- **Безопасность**: Контроль целостности файлов (SHA-256), экспорт доказательств в ZIP.

## Технологический стек
- **Backend**: Python 3.13, FastAPI, Uvicorn
- **ML/Data**: PyTorch (YOLOv8, EasyOCR), TensorFlow (YAMNet), OpenCV, Librosa
- **База данных**: SQLite, SQLAlchemy
